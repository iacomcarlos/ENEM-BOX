# Checklist de publicação — ENEM BOX

- [ ] Repositório criado e todos os arquivos enviados (não apenas o ZIP)
- [ ] `index.html`, `styles.css`, `script.js`, `config.js` e `assets/` na raiz
- [ ] GitHub Pages ativado em Settings → Pages
- [ ] Site testado no desktop e no celular
- [ ] `config.js` preenchido com o link verdadeiro de checkout
- [ ] Nome, CNPJ, contato e links legais revisados
- [ ] Plataforma de vendas configurada para liberar o kit pago automaticamente
- [ ] Materiais pagos guardados FORA do repositório público
- [ ] Questões e gabaritos conferidos por revisores pedagógicos
- [ ] Compra-teste realizada, do anúncio/LP até o arquivo entregue
- [ ] Política de reembolso e atendimento publicados conforme a legislação aplicável
